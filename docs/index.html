Three-Layer Entry Confirmation

01

RSI Crossover

RSI crosses up through the oversold threshold for longs, down through overbought for shorts. Period and thresholds are searched per symbol.

02

KDE Score

Kernel density estimate on RSI history. The current reading must be more extreme than a configurable fraction of the prior 100 bars — filters weak signals.

03

S&D Zone

Price must be inside a higher-timeframe demand (long) or supply (short) zone — formed at confirmed HTF swing lows/highs with zero lookahead bias.

+

Choppiness Filter

Choppiness Index below threshold ensures the market is trending. Ranging markets produce false reversals — this gate filters them out.

Entry Flow

RSI crosses oversold / overbought
↓
KDE score ≥ threshold (statistically extreme)
↓
Price inside MTF supply or demand zone
↓
Choppiness Index < threshold (trending)
↓
SL distance ≤ 1.5% — market entry + set TP (70% swing) / SL (zone) on exchange

Walk-Forward Backtester

|◄────────────────── 48h window ──────────────────►| |◄── IS 24h: search 100,000 param combos ──►|◄── OOS 24h ──►| ▲ params only written to live trader if profitable here Selection metric: Sharpe ratio (raw return% was found to overfit) Cycle: every 30 minutes — always trading the freshest validated params

If all symbols fail validation in a given cycle, the existing params are kept unchanged rather than blanking the config — the bot keeps trading while the BT retries next cycle.
